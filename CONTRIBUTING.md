# Contributing

Create a focused branch from `main`, write descriptive commits and open a PR explaining the user-facing change and checks performed. Keep connection guides accurate and avoid including private data.

After editing the catalogue source, run `npm run catalog`, then run `npm run check` before the PR. The check validates generated catalogue files and is also run by CI. There is no separate lint or test script in `package.json`; review documentation links and examples for changes in scope.
